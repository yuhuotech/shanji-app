入门

快速上手

闪记安装完成后，只需几步即可开始使用语音输入。

  1. 1
    安装并启动闪记，应用会出现在系统托盘（菜单栏）中。
  2. 2
    首次使用需要在设置中下载语音识别模型，下载完成后即可离线使用。
  3. 3
    授予应用麦克风权限（系统会自动提示）。
  4. 4
    将光标定位到任意输入框，按下默认快捷键开始录音，说完再按一次，识别结果会自动贴入光标位置。

配置

下载语音识别模型

闪记使用 FunASR Paraformer 进行本地语音识别，首次使用需要下载模型文件（约 200–400 MB），之后完全离线运行。

  1. 1
    打开闪记主窗口，点击顶部的设置图标。
  2. 2
    进入 ASR 模型 页面，选择需要的模型版本。
  3. 3
    点击下载，等待下载完成（支持断点续传）。
  4. 4
    模型加载完成后，状态栏会显示"就绪"。
网络提示：国内用户如果下载较慢，可以在设置中启用代理，或手动放置模型文件到应用数据目录。

录音模式

闪记支持两种录音模式，适应不同的使用习惯：

推荐

Toggle 模式

按一次快捷键开始录音，再按一次停止并输出结果。适合连续说较长内容的场景。

Push-to-Talk

按住说话

按住快捷键说话，松开即停止录音并输出。适合偶发性输入，避免误触。

可以在设置 → 录音模式 中切换，也可以通过快捷键在两种模式间快速切换。

快捷键

所有快捷键均可在设置中自定义，默认配置如下：

操作默认快捷键（macOS）说明

进阶功能

LLM 润色

开启 LLM 润色后，识别结果会先发送给配置的 AI 接口进行轻度整理，再贴入光标位置。只有文字发送给 LLM，音频始终留在本地。

配置步骤

  1. 1
    在设置 → LLM 润色 中填写服务商的 Base URL 和 API Key。
  2. 2
    填写模型名称（如 gpt-4o-mini、deepseek-chat）。
  3. 3
    选择一个内置提示词预设，或自定义 System Prompt。
  4. 4
    保存后，通过快捷键切换润色开关即可生效。

历史记录

闪记会自动保存每次识别的结果，持久化存储在本地 SQLite 数据库中。

你可以做什么

  1. ·
    查看和搜索：支持全文搜索，快速找回之前的输入内容。
  2. ·
    复制：一键复制历史条目的原始识别结果或润色后的文字。
  3. ·
    音频回放：回放对应的录音片段，确认识别准确性。
  4. ·
    重新转写：对同一段音频重新进行识别（切换模型后可用）。
  5. ·
    删除：删除单条记录或批量清除。
历史记录文件位于 $APP_DATA/shanji/history.db，可以自行备份。

热词库

热词库可以提升特定领域词汇的识别准确率，尤其是人名、品牌名、专业术语等。

内置词库

闪记预置了多个领域的热词库，可按需开启：

  1. ·
    AI 编码与技术
  2. ·
    计算机与互联网
  3. ·
    跨境电商
  4. ·
    自媒体与内容创作
  5. ·
    网络流行语

自定义词库

在设置 → 热词库 中，可以导入自定义词表文件（每行一个词），或直接在界面中编辑。每个词库可以独立开启或关闭。

系统托盘

闪记以系统托盘图标常驻后台，不占用 Dock 或任务栏空间。通过托盘图标可以：

  1. ·
    查看当前状态（就绪 / 录音中 / 处理中）
  2. ·
    快速打开主窗口、设置或历史记录
  3. ·
    切换 LLM 润色开关
  4. ·
    退出应用
建议将闪记设置为开机自启，在设置 → 通用 中开启，这样每次开机后即可直接使用快捷键。

本地实时识别
基于 FunASR Paraformer 实现，音频在本机处理，保障数据主权。
✨
LLM 智能润色
接入 OpenAI 兼容接口，自动修正错别字，去除语气词，让表达更专业。
⌨️
全局快捷键
支持多种录音模式，通过按键操作即刻录音与出文。
🚀
自动输出
识别完成后自动粘贴到当前输入框，支持标点智能整理。
📂
历史记录管理
持久化保存结果，支持音频回放、重新转写及全文搜索。
🎨
原生桌面 UI
Slint 驱动原生渲染，内存占用极低，跨平台无缝体验。

技术规格

工作流
系统实时采集 16kHz 音频，通过 FBank 提取特征，由 Paraformer 模型在本地完成推理。
ASR 模型
Paraformer-zh (支持流式与非流式识别)
推理引擎
ONNX Runtime (优化后的本地推理后端)
开发语言
Rust 1.75+ / Slint UI Framework
本地存储
SQLite 3 (集成 FTS5 全文搜索支持)

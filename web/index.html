技术规格与常见问题

闪记是如何工作的？

系统采集 16kHz 音频，通过 FBank 提取特征，由 Paraformer 模型在本地 ONNX Runtime 环境下完成推理。识别结果可实时展示，并在结束后自动模拟键盘输入贴入光标位置。

技术指标 (Specifications)

  • 推理后端： ONNX Runtime (CPU/GPU)
  • ASR 模型： FunASR Paraformer-zh (流式/非流式)
  • 音频格式： 16kHz, 16bit, 单声道 PCM
  • 开发语言： Rust 1.75+
  • UI 框架： Slint (原生渲染)
  • 数据存储： SQLite 3 (支持 FTS5 全文搜索)

系统兼容性

兼容 macOS (Intel/Apple Silicon), Windows 10/11 (x64), 以及主流 Linux 发行版。极轻量化设计，常驻后台仅占用约 150MB 内存。

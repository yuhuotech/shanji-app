隐私政策

我们用一些直接的问题来说明闪记是怎么对待你的数据的。

核心承诺

  • 音频数据始终留在你的设备上，永远不会上传到任何服务器
  • 不收集任何使用数据、崩溃报告或遥测信息
  • LLM 润色只发送识别后的文字，不涉及音频
  • API Key 保存在系统钥匙串，不写入任何配置文件
  • 所有本地数据你可以随时查看、备份和删除
我说的话会被上传吗？

不会。闪记的语音识别完全在你的设备本地完成，使用的是 FunASR Paraformer ONNX 模型，通过 ONNX Runtime 在本地推理，整个过程不需要联网，音频数据不会发送到任何地方。

你说的每一句话，从采集到识别结束，始终只存在于你自己的电脑上。

开启 LLM 润色后，会发送什么出去？

启用 LLM 润色时，只有语音识别后的文字内容会发送给你配置的 AI 服务商（如 OpenAI、DeepSeek 等）。音频本身从不参与这个过程。

发送的内容大致等同于你在聊天框里手动输入文字让 AI 润色——性质相同，没有额外的数据。你选择什么服务商，就适用该服务商自己的隐私政策。

如果你不希望文字内容离开本地，关闭 LLM 润色功能即可，或使用 Ollama 等本地大模型服务。

本地存储了什么？
数据位置说明
应用配置 config.json 本地 快捷键、模型选择、输出偏好等设置
历史记录 history.db 本地 每次识别的文字结果，SQLite 格式，可随时删除
模型文件 models/ 本地 ONNX 格式的 ASR 模型，约 200–400 MB
API Key 系统钥匙串 本地 由操作系统加密保管，不写入配置文件
录音片段 audio/ 可选 仅在开启音频保存时保留，默认不保存

所有数据位于 $APP_DATA/shanji/ 目录下，你可以随时打开、备份或整体删除。

闪记会收集使用数据或崩溃报告吗？

不会。闪记不内置任何数据统计、崩溃上报或用户行为追踪模块。应用运行期间不会向任何服务器发送任何遥测数据。

这是一个开源项目，代码完全公开在 GitHub，你可以自行审计任何网络行为。

# 闪记（Shanji）产品需求文档

**版本**: v1.0  
**日期**: 2026-03-13  
**状态**: 当前产品定义

## 1. 产品定位

闪记是一款桌面端 AI 语音输入工具。用户通过全局快捷键开始录音，对着麦克风说话，系统完成本地语音识别，并可选进行 LLM 改写，最终把结果输出到当前光标位置。

## 2. 核心价值

- 本地识别，音频不上传
- 低摩擦输入，不切换应用
- 可选智能改写，适合消息、文档和笔记场景
- 原生桌面体验，窗口反馈直接
- 跨平台支持 macOS、Windows、Linux

## 3. 目标用户

- 高频文字输入用户
- 需要快速记录和整理想法的知识工作者
- 希望减少键盘输入负担的桌面用户

## 4. 核心功能

### 4.1 语音输入

- 全局快捷键启动与停止录音
- `Toggle` 与 `Push-to-Talk` 两种模式
- 麦克风设备选择与音量监测
- 录音过程状态反馈

### 4.2 语音识别

- 本地 Paraformer 模型识别
- partial / final 结果反馈
- 模型切换、状态展示、下载与导入

### 4.3 智能改写

- 改写开关
- OpenAI 兼容接口配置
- Prompt 配置
- 改写结果回写到最终输出链路

### 4.4 文本输出

- 自动粘贴到当前输入位置
- 失败时回退到剪贴板
- 输出格式控制
- 历史记录存储、查看、复制、回贴

### 4.5 桌面交互

- 主窗口
- 设置窗口
- 历史窗口
- Overlay 悬浮窗
- 系统托盘

## 5. 产品要求

### 5.1 交互要求

- 主窗口负责展示状态、权限、模型和常用操作
- 设置窗口负责配置管理
- 历史窗口负责回查与复用
- Overlay 必须轻量、置顶、低干扰

### 5.2 性能要求

- 启动后应尽快进入可交互状态
- Overlay 展示和隐藏必须足够轻
- 高频状态刷新时不应造成明显卡顿

### 5.3 可靠性要求

- 长时间后台运行时托盘、窗口和快捷键状态一致
- 权限缺失时给出清晰反馈
- 输出失败时有可回退路径

## 6. 成功标准

- 用户可以稳定完成“按快捷键说话 -> 得到文本 -> 自动输出”
- 历史、模型、设置等辅助能力可正常工作
- 主要平台行为在 macOS 上稳定，并具备跨平台扩展基础

# 闪记（Shanji）开发计划

**版本**: v1.0  
**日期**: 2026-03-13  
**状态**: 原生项目主线

## 1. 当前目标

- 稳定原生桌面主链路
- 补齐设置、历史、模型、热词等管理体验
- 完善 macOS / Windows / Linux 的平台行为
- 准备测试、打包与发布

## 2. 已完成能力

- 原生 UI：`Slint`
- 核心能力：`shanji-core`
- 平台能力：`shanji-platform`
- 主窗口、历史窗口、设置窗口、Overlay
- 本地 ASR、可选 LLM 改写、自动粘贴
- 历史记录、模型管理、热词摘要
- 托盘、全局快捷键、剪贴板与输入模拟
- Cargo 主导的构建与运行流程

## 3. 近期任务

### P0 稳定性

- 做完整人工回归测试
- 补充关键模块单测

- 继续优化主窗口与 Overlay 的布局和响应

### P1 产品完成度

- 完善设置窗口的分组和信息层级
- 完善历史窗口的检索、筛选和复用操作
- 完善模型管理的状态展示与错误反馈
- 完善热词库管理入口

### P1 平台体验

- 补充 macOS 打包说明

- 明确 Linux 托盘、快捷键、输入模拟限制

### P2 工程质量

- 收敛文档结构
- 视需要补充 CI 检查

## 4. 完成定义

- 主窗口、历史窗口、设置窗口、Overlay 可稳定使用
- 语音输入主链路在 macOS 上可完整跑通
- 托盘、快捷键、自动粘贴行为可预测

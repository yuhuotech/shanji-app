## Shanji v{{VERSION}}

本次版本主要完善了托盘体验，并修复了跨平台构建与 macOS 发布流程中的多个问题。

### What's Changed

- 使用应用专用单色托盘图标，替换原有黑色麦克风图标
- 修复 macOS 深色模式下托盘图标不清晰的问题，改为按 template icon 渲染
- 托盘左键改为直接展开快捷菜单
- 托盘菜单调整为四项快捷入口：
  - 显示主界面
  - 系统设置
  - 历史记录
  - 退出
- 新增托盘图标 SVG 源文件及 PNG 资源，便于后续维护和导出
- 修复 Windows 下托盘图标缓存导致的构建失败问题
- 修复 macOS 发布流程中的公证校验顺序
- 修复 DMG 打包时可能出现的 `Resource busy` 冲突
- 修复 notarized DMG 的最终校验方式，改为按 openable item 验证
- 整理官网静态资源目录，统一迁移到 `web/images/`
- 官网相关页面同步更新资源引用

### Notes

- 本次更新涉及托盘图标、托盘菜单和发布流程调整
- 如遇旧托盘图标未刷新，请完全退出应用后重新启动
- macOS 安装包现已完成签名、公证与 stapling 流程

# Security Policy

## Supported Versions

This project is under active development. Security fixes are expected to target the latest `main` branch and the most recent release tags.

## Reporting a Vulnerability

If you find a security issue, please do not open a public issue.

Report it privately through GitHub Security Advisories if enabled for this repository.

If private disclosure is not available, open an issue only when the problem is not sensitive and avoid including:

- API keys
- personal data
- local file contents
- audio recordings
- screenshots that expose private information

## Scope

Security-sensitive areas in this project include:

- microphone access and audio capture
- clipboard access and automatic paste behavior
- input simulation and global hotkeys
- tray and background runtime behavior
- model downloads and update sources
- LLM provider configuration and network proxy settings

## Response Expectations

We will prioritize:

1. confirmation of the issue
2. reproduction and impact assessment
3. fix or mitigation
4. release note if applicable
